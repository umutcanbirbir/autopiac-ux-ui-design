## Scope
The first wireframes focused on the layout and order of the seller's listing steps before adding the yellow-and-white color scheme.

## Screen Inventory
| Screen | Primary UI | Main action |
| --- | --- | --- |
| 01 — Start | Short requirements summary, "Create listing" button, progress overview | Begin |
| 02 — Vehicle Details | Make, model, year, mileage and help text | Continue |
| 03 — Photos | Photo area, minimum count and cover-photo guidance | Continue |
| 04 — Price & Description | Price, currency, condition notes, description | Continue |
| 05 — Review | Summary of all sections, edit links, clear validation feedback | Publish |
| 06 — Success | Prototype completion and next actions | View listing |

## Critical States
- **Insufficient photos:** The screen explains that at least five photographs are needed.
- **Invalid vehicle data:** One or more required details are missing; error summary and field-level cues allow correction.
- **Submission failure (optional additional state):** Planned for a functional version; not shown in the current Figma flow.

## Responsive Design
The mobile frames use a 390 px width with single-column forms. The desktop Vehicle Details example uses a wider layout with a separate guidance panel.

## Design Approach
- Auto Layout for major structures and form rows.
- Reusable simple controls where practical.
- Content hierarchy and readable labels.
- The screen links were added during the prototype stage.
